# Windows Spotlight

A Windows-focused Spotlight-style reminder application that allows users to create reminders using natural human language.

## Project Overview

Windows Spotlight is designed to provide a fast Spotlight-style interface for creating and managing reminders.

The application is being developed as a native Windows application using C++.

The project originally started as a Python prototype. The Python version is being kept temporarily as a reference while the C++ version is developed.

## Technologies

- C++
- CMake
- Qt
- SQLite
- Windows Notifications
- Local AI model for advanced natural-language understanding (planned)
